# 번역기 (한·중·일·영)

말소리를 듣고 글자로 번역해 보여 주는 무료 번역기입니다.

## 내려받기

- 안드로이드 폰: https://github.com/everest8848won-ai/translator/releases/latest/download/translator.apk
- 윈도우 컴퓨터: https://github.com/everest8848won-ai/translator/releases/latest/download/Translator.exe

## 모드

- 대화 모드: 시작을 누르면 한 문장만 듣고 번역합니다.
- 강의 모드: 시작을 한 번 누르면 정지할 때까지 계속 듣고 자막처럼 번역합니다.

## 처음 실행할 때

음성 모델(약 40~80MB)과 번역 언어 파일(폰은 언어당 약 30MB, 컴퓨터는 약 620MB)을
한 번만 내려받습니다. 그 뒤로는 인터넷 없이 동작합니다.

## 사용한 무료 도구

- 듣기: Vosk (강의 모드), 폰 기본 음성인식 (폰 대화 모드)
- 번역: 폰은 Google ML Kit, 컴퓨터는 NLLB-200 (비상업용)
